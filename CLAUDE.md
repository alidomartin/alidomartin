## Project Overview

Sports performance analytics for volleyball. Two primary workstreams:

1. **CMJ Phase Visualizations** — Python script generates annotated force-time curve images for each countermovement jump phase. Used in the GitHub profile README.
2. **TSA Reports** — R scripts calculate and visualize the Total Score of Athleticism from CMJ metrics.

Data source: Hawkin Dynamics force plates. Sampling frequency: 500 Hz.

## Running the Scripts

### CMJ Phase Plots (Python)

```bash
python generate_plots.py
```

Requires: `numpy`, `matplotlib`, `scipy`
Output: `images/*.png` (11 files at 150 DPI)
Regenerate whenever phase logic or styling changes.


Requires: `ggplot2`, `dplyr`

## Metric Conventions

All metric labels are defined in `01_Identity/GLOSSARY.md`. Use those labels verbatim in all output text, table headers, and code comments.

| Metric | Label | Unit |
|---|---|---|
| Total Score of Athleticism | TSA | dimensionless |
| Relative Peak Power | Relative Peak Power | W/kg |
| Modified Reactive Strength Index | RSImod | m/s |
| Jump height from CMJ takeoff velocity | Vertical Jump Height | m |

**TSA formula:**

```
Z = (x - mean(x)) / sd(x)
TSA = Z(Relative Peak Power) + Z(RSImod) + Z(Vertical Jump Height)
```

Z-scores are session-relative. TSA is signed: positive = above group average.

## Design System — Japanese Editorial

All visualizations (R and Python) follow this palette and layout standard.

### Colors

| Role | Hex | Name |
|---|---|---|
| Background | `#2C3E50` | Slate |
| Accent / highlight | `#77DD77` | Warm Eucalyptus |
| Body text | `#FFFFFF` | White |
| Muted text | `#8FA3B1` | Dim |
| Header band | `#1E2D3D` | Dark Slate |
| Row stripe (even) | `#253545` | Mid Slate |
| Grid / dividers | `#3D5568` | Rule |

### Layout Rules

- Dark background, high-contrast text. No light-mode outputs.
- Grid-based. Column dividers as thin rule lines (`#3D5568`, 0.2 linewidth).
- Minimalist. No borders around the full table, no drop shadows, no gradients.
- TSA column rendered in ACCENT color to distinguish the composite score.
- Accent bar on the left edge of the header band.
- Bottom rule in ACCENT color.
- Title in ACCENT, bold, uppercase.
- Formula subtitle in DIM color, plain weight.

## Code Style

### R

- Use base pipe `|>` (R 4.1+).
- Use `dplyr` verbs for data manipulation.
- Use `ggplot2` for all visualizations.
- Two `geom_text` layers (plain and bold) rather than mapping `fontface` as an aesthetic, for compatibility across ggplot2 versions.
- `scale_color_identity()`, `scale_fill_identity()`, `scale_size_identity()` for direct color/size control.
- Save outputs with `ggsave()`. Always specify `bg` argument to match the background color.

### Python

- Functional style. One function per logical unit (`build_cmj_curve`, `plot_phase`, etc.).
- Constants at the top: `BW = 700` (body weight, Newtons), `FS = 500` (sampling rate, Hz).
- Section dividers with ASCII rule comments: `# ─────────`.
- Save with `dpi=150`, `bbox_inches="tight"`.

### Both

- No em-dashes in comments, output labels, or text.
- No filler phrases ("it is worth noting", "importantly", "please note").
- Comments describe what the code does. Skip obvious ones.
- No trailing whitespace.
