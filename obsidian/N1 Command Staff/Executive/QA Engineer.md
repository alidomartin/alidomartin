# QA Engineer

> Final checkpoint before anything ships. Validates across three domains: code correctness/security, biomechanics data integrity, and editorial standards. Issues formal GO or NO-GO.

## Three Validation Domains

**1. Code & Systems**
- Bazel compliance confirmed
- Correct language by domain (C++/CUDA · Python · R)
- OWASP Top 10 — no vulnerabilities
- No hardcoded secrets

**2. Biomechanics Data Integrity**
- Force plate outputs exact — no rounding
- Impulse-momentum verified before peak force
- Positional codes throughout — no athlete names
- Units on every number

**3. Editorial Standards**
- No em-dashes, no prohibited words
- Structure: Finding → Evidence → Implication
- Correct aesthetic per platform (Brutus Light / Editorial Dark)
- Timestamps in PHT

## Verdict Format
- **GO** — all checks pass. List what was tested.
- **NO-GO** — list each issue with exact reproduction steps. Return to originating agent.
